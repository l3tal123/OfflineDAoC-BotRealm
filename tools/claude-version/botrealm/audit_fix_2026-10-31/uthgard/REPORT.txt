HOW
- Uthgard drop name -> Uthgard item page of that name (AUDIT/work/items/item_sources.json, parsed from the raw
  archive item.php?load=N pages): the page whose "Item can drop from these monsters" list names the same Uthgard
  monster, else the lowest load id. One built item per page; plain pages with the same name AND sell value share one.
- An existing usable ItemTemplate of the exact name (realm fits, not removed by the drops agent / stage3 rules, no
  cq_, no freeshard package) is used instead of building.
- Plain loot (no stats): Object_Type 0 / Item_Type 40, Realm 0 (vendor loot is realm-free, like the gems the drops
  agent built), Level from the page, Price = Uthgard sell value x 2 (server item_sell_ratio 50, so merchants pay the
  Uthgard value), always tradable/droppable; look (Model/Color/Extension/Weight) from the closest existing plain
  loot item: 198 same last word (pelt->pelt), 222 shared name word, 110 nearest price (no shared word: look is a guess, marked); remains/trophies use an existing
  remains item. Quest-credit / token / ticket items and untradable items are never used as siblings.
- 41 built items have no Uthgard sell value: their price comes from the sibling (marked in built.csv).
- Equipment: level, slot, object type, AF/absorb or DPS/speed, damage type, quality and bonuses from the page;
  realm = the monster's realm; look, hand, AllowedClasses, weight, durability from the closest sibling (same object
  type + slot + realm, shared name words, nearest level). Bonus types eProperty 99-119 / 145-256 are dropped and
  listed (none of the built items had one). Not built: procs (the page names no spell).
- Rates: n / max(kills, 20) of that monster's realm-matched Uthgard records, 1-100 %. drop_count: raid 4, named 2,
  regular 1 (2 when the rolled chances add up to 50 %+), as the drops agent.

JUDGEMENT CALLS
- Uthgard 'Experience' items (20 rows, e.g. Long White Boar Tusk, Squabbler Eye, Giant Snow Crab Claw, Grovewood
  Bark) are Uthgard's XP-item turn-in mechanic (its 'XP items' menu) = the Atlas XP-item idea the owner banned;
  several are exactly the AtlasXPItem rows the drops agent removed. Skipped. If the owner wants them as plain
  sellable loot instead, they are listed in not_built.csv with their load ids.
- Vae Inimicus War Mattock (p165_uth_2749): the page shows a weapon proc (level 35) with no spell -> built without the
  proc; Uthgard gives no sell value, so the price is the sibling's (adamantium war mattock).
- harvestman carapace: the page says slot torso but has no type or stats -> built as plain loot.
- Items whose plain-loot look comes only from the nearest price may look odd in the inventory (e.g. a necklace
  shown as fish): marked "nearest price" / "shared name word" in built.csv; the coordinator can pick better models.
