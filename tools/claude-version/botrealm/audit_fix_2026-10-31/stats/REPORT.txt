HOW VALUES WERE SET
1. Period page (period_item_pages.jsonl via the items-agent cache work\items\item_sources.json = pageparse.parse +
   build_vendoritems165.page_stats / map_bonuses, plus analyze.page_bonuses for alias lines). Match: same name
   (Allakhazam tags stripped), realm equal or 0, page object type and slot equal to the row's, class restriction
   compatible; among several pages: closest AF/DPS, then closest bonuses, then latest capture. Allakhazam "Unique
   Item" (random item) pages never used. Set: Bonus1..10 (+types) in page order, unused slots 0/0, ExtraBonus 0/0,
   DPS_AF/SPD_ABS (armour: Armor Factor/Absorb; weapons: DPS and Delay x10; shields/instruments untouched), Quality.
   Mapping: "Power N pts" -> MaxMana 9 (points); Longbow/Composite Bow/Recurve Bow -> 36/68/83; "Bow N pts" (old
   pages) -> the row's bow skill; "ALL Magic Skills" twice (dragon staves) -> AllMagicSkills + AllFocusLevels (the
   larger line); old "Focus Bonuses: - X: N lvls" lines read from the raw page (pageparse skips them); on staves a
   magic-line "+N pts" above 15 is focus levels.
2. Uthgard page (raw item.php pages, same cache): same name, slot/armour type consistent, closest level. Bonuses,
   AF/DPS/speed/absorb, Quality and Level (Uthgard's item level is a DOL level). ToA-only types never taken from
   Uthgard.
3. Stripped only: the row keeps its own values; every ToA-or-later bonus slot is zeroed (except decision 2). One
   conversion: unified Skill_Archery -> the row's period bow skill (bow object type 9/15/18, else realm), 27 items
   (report_data.json "archery_renamed"). PowerPool %, ExtraHP %, AllArchery removed, not converted.
Never changed: spells/charges/procs, Id_nb, Name, Model, Color, Object_Type, Item_Type, Price, Bonus %,
AllowedClasses.

JUDGEMENT CALLS
1. Item Level on period-page items: Allakhazam pages give no DOL item level ("Level to Attain" equals the DOL Level
   on only 57% of untouched items). Left alone, except when the page moves AF/DPS so far that the old level no longer
   fits (DOL rule cloth AF = level, other armour AF/2, weapons (DPS-1.2)/0.3; > 2 levels apart): 48 items.
   Uthgard-sourced items take Uthgard's Level (366 items; most Apr-28 decision-1 items get Uthgard's level, which is
   often a few levels higher, e.g. 35 -> 41).
2. Apr-28-2003 bulk date: see decision 1.
3. Pre-rename resist names: 47 period pages list "Earth/Wind/Dark/Light/Mana/Mind/Void Resist" (Allakhazam's 2001
   data; no such resist in 1.65). Not used (-> Uthgard, else stripped/unchanged).
4. Stale by their own patch note (8 pages, read by hand, not used): 4173 Sword of the Fiery Heart ("now has stat
   increases", page lists none); 2532 Ancient Dragon Etched Coif + 2882 Wolftooth Hauberk (pac replaced, page still
   lists Pacification); 2003 Shrunken Bear Skull (Beastcraft); 6355 Mace of the Valiant (Valor); 4596 Doomcaller (Body
   twice); 2478 Bear Claw Talisman, 5987 Verdant Ornate Ring ("granted higher bonuses", cannot tell).
5. Pages with no bonuses: used as "plain item" only when Uthgard also lists none (Aged Mithrian Cloth Pants, Adorned
   Recurve Bow) or the page was edited after the bulk date with Default Bonus 0% (10 rows end with no bonuses, e.g.
   Crafted Darksteel Composite Bow, Old Noble's Gauntlets). Not used when: bulk-dated (48 rows), Uthgard lists bonuses
   (7), focus staff (4), jewelry slot or Default Bonus > 0% (1).
6. ToA-looking types on an item's own pre-ToA period page are kept (list A).
7. Same-name Atlas copies (1_, 2_, 3_, Shining_, Bright_, Brilliant_, Shimmering_ ...) carrying the period item's
   exact in-game Name get the period item's stats (248 period-sourced rows), which can lower them a lot (Bright
   Decaying Hammer 9.6 -> 4.8 DPS, Level 30 -> 12). Whether these copies should exist is the freeshard/drops agents'
   call; 7 of my statements hit items marked REMOVE in item_actions.json (harmless: remove rules run before updates,
   an UPDATE on a missing row does nothing). Real class variants (different AllowedClasses / object type) only get
   a page that fits them (2 rows skipped).
8. DPS: the page's "DPS:" field is used, not the "Base DPS" modifier line (Truesilver Recurve Bow: DPS 14.6,
   "Base DPS: 3.10" = the viewer's clamped value).
9. "Above its period page" items without later types were changed only when that page was usable (58 left alone).
