BOTREALM v0.2

This folder is the server, the launcher and the clean world. The game
client is supplied separately. It contains no one else's account,
characters or bots.

There's nothing to install or turn on in Windows: .NET is included in
tools\dotnet, and the game uses only that copy. You don't need the Windows
".NET Framework 3.5" feature (only the old Offline DAoC's original client
needed it), the Visual C++ Redistributable, or an original DAoC client.

WHAT YOU NEED
A 64-bit Windows 10 or 11 PC whose CPU supports AVX2 (the bots' navigation
needs it; most CPUs from 2014 onward do), a graphics card that supports
Vulkan (current drivers), and 16 GB RAM recommended.

PLAY
1. Keep this whole folder together. Don't run files from inside a ZIP.
2. Double-click START BOTREALM.cmd. The launcher shows VERSION 0.3.
3. Click START SERVER and wait until the launcher shows RUNNING.
   The first start sets up the world and can take a few minutes.
4. Click ENTER REALM. Your own local account is created the first time.
5. Add bots with the + Lv.1 button on each realm's card (Shift = 10,
   Ctrl = 100). Start small and add more as your PC allows.
6. To finish: quit the game, click STOP SERVER, and wait for it to save.
Only one server can run at a time.

COMPANIONS
At level 5 a courier sends you to your realm's traveler's inn (near Caer
Witrin, Huginfell or Connla). The innkeeper hires companions. More slots
open at levels 5, 10, 15, 20, 30, 40 and 45.

A FRESH START
BotRealm is its own game. Saves from Offline DAoC 0.37 and earlier can't be
brought over.

UPDATING
A new version updates this folder in place: get the new downloader from the
latest release on GitHub, run GET-BOTREALM.cmd and choose
1 = Update my game. Your save and settings stay; the files it replaces are
backed up in patch-backups\.

YOUR SAVE
Your world, characters, companions and bots are in
runtime\data\opendaoc-165.sqlite3.db. Back it up before you try a new build
or a mod.
