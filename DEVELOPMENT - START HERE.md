# Developer start

BotRealm **v0.2**. One world. The game client is supplied separately; it is not part of this repository.

Read these first:
- [AGENTS.md](AGENTS.md): the project rules and the layout.
- [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md): building and testing the server and launcher, how the BotRealm world content
  reaches the world, the generators, the clean database and the release runtime.
- [docs/LLM-QUICKSTART.md](docs/LLM-QUICKSTART.md): customizing it with your own AI assistant.

Work in a copy of a playable folder, keep saves out of commits, and report automated tests separately from in-game
checks.
